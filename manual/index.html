MAP GENERATION # seeded value-noise + fBm + ridge

A map is not drawn — it's generated from a single integer seed. Same seed → same map, every time.

Three noise fields are compositied in priority order: 4-octave fBm value-noise (red seam mask) → smoothstep×noise diagonal bands (green rot lines) → sparse fBm with cellular smoothing + a Chebyshev distance transform (blue pockets).

Every seed reliably produces the same three signatures — pure red seams along ridge lines, green rot bands running one snap-to-8 angle across the map, and blue pockets in tight round blobs. Reroll and see.

0 · EMP · SALVO PATTERNS

                  
EMP costs 200 BLUE purity + 250 credits per warhead. One warhead = one salvo = 3 missiles fired simultaneously. Each missile spawns a Manhattan-radius-2 cloud (13 cells) that lives 8 hours. The rack is public and capped at 600 BLUE (§4.9.8). Its small cousin SNAP (§4.9.4, v1.36) is 100 BLUE + 250 credits for one missile on one square lasting one hour — the difference that matters is not the size but the timing: SNAP lands ABOVE the hour's vision snapshot, so a probe it kills cannot light a drop that same night. An EMP on the same beacon in the same hour cannot do that.

0 · CHAFF · BASICS

                  
CHAFF costs 300 BLUE purity per flare. At hour N it cancels every seat's action for hours N, N+1, N+2. Launcher is immune only at hour N and self-jams for the carry-over. Two things chaff can do that nothing else can: deny an H1 drop and strand an opponent's harvester. A launch is an action too: a flare, EMP or SNAP queued into a jammed hour is cancelled with its munition intact, so chaff cannot be chained and beats a same-hour EMP. One exception (v1.57): a SNAP declared for the hour you fire outruns the flare and still lands, spending its charge — to jam a SNAP the window has to be up already. The rack is public and capped at 600 BLUE (§4.9.8) — two flares is the most you can carry, and at 300 apiece a chaff buyer reads the same on the public bar as three SNAPs would.
